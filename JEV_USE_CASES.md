# Jev Use Cases

Jev is a small, fast, cheap model. Use it for the narrow, high-volume jobs so the expensive model only does the thinking. Source: shipwithjev.com.

## Token-efficiency use cases

| # | Use case | Output |
|---|---|---|
| 1 | Model routing per task with effort level | Right model and effort chosen before the session starts (not mid-session, that breaks the cache) |
| 2 | Pick the right skill | Skill name in far less time than Opus scanning the skill list |
| 3 | Jev on / off skill | Toggle per session |
| 4 | Code graph + Jev | Jev answers "where is X, what calls Y" from the graph so the main model never greps |
| 5 | Cheap metadata writer | Image and file descriptions written once, searched many times |
